获取物品

/give

选择物品、调整数量与目标，生成给予指令。
基岩版：/give <目标> <物品> [数量] [数据值]　Java版：/give <目标> <物品>[count=<数量>]

提示：要附带附魔，请使用「附魔」标签页的装备附魔。OP/隐藏方块（命令方块、屏障、基岩、光源方块等）请在分类 chips 选择「OP/隐藏方块」。

附魔

enchant · give+enchantments

两种附魔方式：简单附魔直接对玩家手上的物品附魔；NBT附魔通过 NBT 给予带多重附魔的新物品。

0 = 移除该附魔；滑块上限 = 该附魔的最大等级
简单附魔只对玩家当前手持的物品生效（无需指定物品）。多个附魔请多次执行或加入组合。
提示：每条附魔独立调节等级，超过最大等级也会生效（超出上限效果可能未定义）。

状态效果

/effect

为实体添加状态效果。
基岩版：/effect <目标> <效果> [秒数] [倍率] [隐藏粒子]　Java版：/effect give <目标> <效果> [秒数] [倍率] [是否隐藏粒子]

或勾选下方「无限时长」
0 = 等级 I，1 = 等级 II，依此类推

游戏规则

/gamerule

切换服务器与世界的规则。布尔型规则用开关，数值型规则用数字。语法：/gamerule <规则> <值>

说明：死亡保留物品栏
常用：keepInventory 保留物品栏，doDaylightCycle 昼夜循环，randomTickSpeed 随机刻速度（影响作物生长），mobGriefing 生物破坏方块。

召唤实体

/summon

在指定位置召唤实体。语法：/summon <实体> [位置] [名称]

玩家操作

gamemode · xp · kill · tp · tag

模式切换、经验、清除、传送、标签等玩家相关指令。

0 = 不限半径；若选择「自己」半径无效

世界控制

time · weather · difficulty

控制时间、天气、难度。

0 = 午夜日出，6000 = 正午，12000 = 日落，18000 = 午夜。范围 0-24000。
留空也可；这里给出明确时长便于控制。
提示：peaceful 不生成敌对生物且自动回血；hard 僵尸破门、饥饿可致死。

方块操作

setblock · fill

放置或填充方块。

粒子音效

particle · playsound

生成粒子或播放音效。粒子语法：/particle <效果> <位置>；音效语法：/playsound <声音> [玩家] [音量] [音调]

音量大于 1 仍可听到，但声音范围会扩大
0.5-2.0；越高音越尖
语法（基岩）：/stopsound <玩家> [声音]　Java：/stopsound <玩家> [来源] [声音]
留空声音名将停止该玩家正在播放的全部音效。

标题消息

title · tellraw

在屏幕上方显示标题，或在聊天栏发送富文本消息。

提示：先设置时间再设置文字（顺序很重要），或直接复制两条指令加入组合。
将生成 JSON 文本：{"rawtext":[{"text":"..."}]}，自动包裹颜色/样式。
语法：/say <消息>
以服务器身份向所有玩家发送消息，前缀为 [@]。可用 @p 等占位符。
语法：/me <动作>
以执行者身份发送动作消息，前缀为 * 玩家名。

清理伤害

clear · damage

清除玩家物品栏或对实体造成伤害。

0 = 清除该物品全部；选择「全部物品」时此值无效
基岩版 1.18.10+ 才支持 /damage 指令

生成计分

spawnpoint · setworldspawn · scoreboard

设置生成点与世界出生点，或操作计分板。

提示：设置后新加入玩家将在该位置生成。所有玩家死亡后会在个人生成点重生。
基岩版计分板使用 dummy 准则（手动计分）。常用：金币、击杀数、死亡数。

物品栏槽位

/replaceitem

在玩家/实体的指定槽位替换物品。语法：/replaceitem entity <目标> <槽位> <物品> [数量] [数据值]

提示：头盔栏可放南瓜/龟壳；副手栏可放地图/盾牌。槽位号从 0 开始。

常加载区

/tickingarea

指定区域保持常加载（红石、生物、作物生长持续更新）。语法：/tickingarea add <起点> <终点> [名称]

提示：常加载区最多 10 个，每个最多 512×512 方块。范围越大性能消耗越高，建议克制使用。

克隆方块

/clone

把一个区域的方块复制到另一处。语法：/clone <起点> <终点> <目标> [模式]

提示：masked 只复制非空气方块（保留目标原有方块）；replace 全部替换；区域最大 32768 方块。

实体事件

/event

对实体触发特定事件（如僵尸转溺尸、村民成长）。语法：/event entity <目标> <事件>

提示：事件需匹配实体类型才生效（僵尸事件对村民无效）。基岩版 1.16+ 支持此指令。

结构建造

/structure

保存、加载或删除结构（可在世界间复用建筑）。语法：/structure <save|load|delete> ...

提示：存到磁盘 的结构可在不同世界间复用；不勾选则只在当前世界内存中可用。
提示：含水方块 保留水；忽略方块 只加载实体不加载方块。
提示：删除会从该世界移除保存的结构。仅删除 内存中 的结构；存到磁盘的结构需手动清理。

HUD 界面

/hud

隐藏或恢复玩家屏幕上的 HUD 元素（适合截图、演出、小游戏）。语法：/hud <目标> <hide|reset> [元素]

选择「all」可一次性操作全部元素
提示：/hud 没有 show，恢复用 reset。省略元素名（选「all」）等价于对全部元素生效。基岩版 1.20.80+ 正式可用。

骑乘

/ride

让实体骑乘、下坐骑，或召唤坐骑/骑手。语法因模式而异，riders = 在上者，ride/rides = 在下者。

提示：基岩版骑乘受实体 minecraft:rideable 组件限制，并非任意组合都能骑（如玩家不能骑僵尸）。召唤类模式会先创建实体再尝试骑乘。
